# 📰 Full-Stack Blog Platform (Django + React)

This is a personal blog site built from scratch with a Django REST API backend and a React frontend. It allows admin users to create articles with multiple tags, and the frontend fetches and displays them via RESTful endpoints.

---

## 🔧 Tech Stack

- **Backend**: Django, Django REST Framework (DRF), SQLite
- **Frontend**: React, Tailwind CSS
- **API Style**: REST

---

## 🚀 Features

- Admin article creation with title, content, and tags
- Tag management via Django admin
- REST API to get and post articles
- React frontend to display articles and their tags
